This project contains an implementation of Conway's Game of Life, a cellular automaton, developed using Wolfram Mathematica. The project simulates the evolution of a 2D grid of cells, following simple rules based on the number of live neighbors. The grid is visualized dynamically, showcasing how various patterns emerge and evolve over time. The implementation can be easily run in Wolfram Mathematica, and the code allows for customizable grid sizes and generations.
